# Osmon Djumagulov Portfolio

Next.js 15 (App Router). No extra libraries, all motion is CSS plus small React hooks.

## Run locally
```
npm install
npm run dev
```
Open http://localhost:3000

## Where to edit
- `lib/data.ts`: projects, news headlines, ticker words, resume content, contact links
- `app/page.tsx`: home page layout
- `app/resume/page.tsx`: resume page
- `app/globals.css`: all styling. Change `--acc` at the top to swap the accent color.
- `public/Osmonbek_Djumagulov_Resume.pdf`: replace this file to update the downloadable resume
- `public/connected-privacy.html`: ConnectED privacy policy, live at `/connected-privacy.html`
